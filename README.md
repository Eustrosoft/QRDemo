# Подготовительный этап

Необходимые средства:
- Maven 3.6.5 и выше
- Java 1.8b301 (OpenJDK)
- Postgres 14.1
- Minio

В подготовительном этапе также необходимо запустить Minio и Postgres - убедиться, что к ним есть доступ

В папке `/dev/` присутствует тестовый `docker-compose` файл для запуска необходимых сервисов в докере
